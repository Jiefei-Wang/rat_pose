# Overview
- The goal for this project is to build a pose tracking pipeline for rats. 
- This project is based on the python package DEEPLABCUT. It requires conda environment, the environment name is either DEEPLABCUT or deeplabcut. Within the conda environment, pytorch is available
- The project is in the "projects/rat" folder. The modules are in the "modules" folder. Additional test code is in the "scripts" folder.
